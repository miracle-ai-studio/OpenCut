设计决定与实施边界

编辑历史不下载。编辑历史回答“谁在何时改了什么”，导出记录回答“产物是什么、是否完成、在哪里下载”。图片中的时间、文件、字体和状态均为设计示例。

区域主要行为收敛与保留
资源卡片单击或键盘 Enter 在独立素材预览上下文查看；不移动时间轴播放头，不改变工程。悬停或聚焦显示操作。移除卡片下方整行“预览／放置／更多”。名称留在下方；时长浮在缩略图；加号和更多放在卡片内。无悬停设备保留可访问入口。
新增与应用＋仅新增元素；“应用”仅修改明确选中的兼容对象，提示目标名称。无明确目标时禁用，并解释原因。默认文字卡片＋新建文字；字体卡片应用到选中文字。特效的片段与图层两模式分开；转场只作用于明确接缝。
媒体／声音／图形拖到兼容轨道及精确时间；幽灵范围反映实际时长；空白可创建相应类型轨道并预告；碰撞需要明确插入方式。点击加号作为键盘与非拖拽替代。音频只读试听独立，不改时间轴。
字体／字幕字体落到可编辑文字替换字体并保留内容、时间、动画和其他样式。字幕列表、轨道与属性同一选择。不可编辑旧文字、缺字、不支持字重及不兼容字幕入口明确提示。字体仅加载可见卡片；加载失败不把系统字体冒充正确预览。
特效／转场特效落到片段为附着效果，落到效果轨为区间层。转场只覆盖相邻片段接缝；已有转场时预览替换结果。资源区不再放整套目标选择、时长、删除表单。选中轨道对象后在右侧调整；接缝可直接拖边改时长。转场不挪动相邻片段。
时间轴片段主体移动，边缘裁剪，接缝选转场，播放头定位；命中互不争抢。拖到边缘持续滚动，Esc取消。保留撤销、重做、分割、删除、吸附、联动、缩放、适配。删除重复“移动／修剪”表单入口；精确时间仍在属性和上下文菜单可达。
缩放／滚动缩放杆与加减按钮统一指数尺度。滚轮缩放以指针为锚点；滑杆以可见播放头为锚点，不可见时以视口中心为锚点。水平滑条仅平移。细轨道、可见矩形滑块，命中区至少28px；缩放、平移不提交工程修改。
预览与参数时间轴、素材、效果示例三个上下文有标签；退出恢复原位置。数值草稿即时预览，确认／松手提交一次；Esc还原。卡片悬停只播放有界缓存样片，离开／切分类／切工程取消；不能每次悬停生成新导出或写工程。
历史／版本摘要、对象、时间、作者紧凑展示；详情按需展开。恢复整版先显示目标及影响，恢复后可撤销。没有下载。常用“查看”直接可达，撤销某条与恢复整版语义分开；保存结果不明确时先核对。
导出设置→进度→成功／失败留在同一流程；收起后到导出记录找任务。记录显示名称、规格、状态、可用操作。无重复标题、无卡片套卡片。常规记录行48–56px；错误和长名称允许展开。弹窗标题与操作固定，正文单层滚动。
删除／移除分别命名删除片段、删除效果、删除转场、从素材库隐藏。素材正在使用时展示影响与定位入口。本稿选择“隐藏素材库引用但保留时间轴／源文件”的安全目标语义；需单独核查现有端口，不等同于已有删除接口。

几何与数据的实施规范

生成图片表达视觉层级和状态，不能直接作为时间坐标算法或像素量尺。实现时使用精确时间模型：像素位置=(时间−可见起点)×每秒像素数；片段宽度=时长×每秒像素数；转场的显示／命中范围覆盖接缝，不占据额外时间。放大的短片段手柄和接缝命中区不改变真实片段范围。

第01板：工程42秒／25fps；媒体源15秒，所选已裁剪片段12秒12帧。第03板：片段A为0–10秒，B为10–20秒，交叉淡化0.5秒跨10秒接缝，播放头8秒。第05板：三字幕分别0–5、5–10、10–15秒；源素材15秒，选取2–10秒；窄窗口的时间轴总长42秒。这些数值作为落地时的权威示例数据，图中示意线不替代测试。

当前能力映射

已有可复用基础包括工程历史、单次事务、媒体／文字／图形创建、模糊效果、交叉淡化、预览及导出任务。字体完整卡片库、内部资源拖放、显式目标轨道、接缝直接编辑与部分参数草稿预览需接线或实现。卡片只陈列能执行的资源；图中字体现实可用性及授权仍需核实。

任务创建时间和展示名称需从共享 Rust 数据链补齐；禁止由ID、当前时间或列表顺序推断。导出文件名、编码／尺寸／帧率选择、画布色彩空间可编辑性、素材库隐藏语义均属于待核实的设计目标，不能把图中控件当成已支持。新增公开字段必须由同一Rust声明生成SDK／OpenAPI／工具类型。

交付与验收

本轮仅交付图片设计稿。独立 UI 子 agent 复核信息架构、动作含义、文字、图片布局及状态覆盖；这不证明真实浏览器手势、设备、渲染、保存或导出已经通过。产品实施后仍需在同一候选与自有测试工程验证1280×720、1440×900、1920×1080、深浅主题、长文本、键盘、取消零写入、一次手势一次提交、未知结果恢复、撤销／重做／重开与实际预览。
