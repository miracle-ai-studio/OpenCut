# 工程交换包

当前唯一入口为 `opencut_project_package_export`、`opencut_project_package_inspect`、`opencut_project_package_import`。Rust 声明位于 `api-contracts/project_exchange`；Host、SDK 和 Web 共用它，不提供开发代际选择。当前源码完成静态接线，尚未统一生成、构建或运行验收。

导出固定 `project_id/revision`，以 `scope=saved_revision|history` 选择保存内容，以 `mode=self_contained|linked` 选择资源存放方式。完整历史捕获要求同一 SQL 读快照中的主线头仍与请求修订相同；保存单个修订不移动主线。历史包含所有保留修订、原因果日记、事务结果、时间、分支和合并父边，不静默丢弃不认识的祖先或操作。当前混合历史文档的无损日记适配仍未完成，保持明确拒绝，不能把它写成完整历史已交付。

新包只有一种清单和 `archive.json`，不写开发 schema 计数或协议选择器。`project_archive` 是共享的类型化闭包校验、资源盘点与身份重映射内核。当前文档只省略内部存储标签；原历史请求和不可变来源证明保持其原身份。媒体、字体按内容 SHA 去重，包含未使用和历史删除的资源；派生字体来源及完整证明随包保存。自包含模式要求文字、字幕、文字蒙版绑定固定字体；链接模式明确报告外部字体族和目标环境事实。

媒体复制、摘要和 CAS 捕获使用固定大小块。新包不把原素材总字节或历史包旧固定额度当作 RAM 准入；大小仍须能由整数表示，并受实际磁盘容量和原存储准入约束。字体解析、JSON、插件执行与包目录另有各自边界，不用于限制普通媒体驻留。旧文件读取器保留其原格式校验，不据此声称整个导入、预览和导出链已支持任意大源。

插件策略在读取固定工程修订的同一 SQL 快照中捕获，包括禁用项；它是导出时当前策略，不冒充该修订创建时的历史权限。WASM 与声明式预设复用原包校验器、目录摘要和固定依赖身份，包目录按 `plugins/{wasm|presets}/{sha256}` 存放；每个策略与精确包身份逐项匹配。全局权限仅作为可审阅提案，宿主授权文件和临时文件不打包。插件总字节上限仍为原 256 MiB，策略数上限仍为原 128。

导入要求检查所得清单 SHA、目标 ID 和原幂等键。所有不可信字节先验证，媒体再流式进入私有暂存并捕获到 CAS；当前包的文件读取锚定目录描述符。新请求无论读取当前还是历史文件，均使用同一请求 family、回执和发布事件。工程、所有修订/日记/分支/合并边、字体证明、回执、审计与 outbox 一起提交，CAS 收集围栏保持到发布完成；失败不留下可见半工程。导出只原子发布新目录，不覆盖既有目的地。

导入不恢复会话、凭据、运行任务或租约，也不安装插件或应用权限。回执的 `plugin_restore_plan` 先列携带必填预期 SHA 的 `opencut_plugin_install`，再列目标工程的授权提案。Owner 审阅后分别执行；可删减或拒绝权限。每项动作独立原子提交，整组不是一个数据库事务。执行安装提案时原包目录必须仍可用；固定 SHA 防止检查后替换内容。重放导入返回原回执，即使目录已移除；历史计划不表示当前安装和授权状态。

FFmpeg/ffprobe 的实际依赖版本和二进制摘要仍是必要身份。工具不可用时不阻止保存工程，而是明确缺少锁；检查报告目标工具差异和缺失字体。清单和资源齐全不等于像素、PCM 或精确可复现证明。

历史文件只由内部读取器按真实清单内容识别一次，不允许调用者切换旧写入协议或解析失败后换格式。旧插件标签、文件布局、原请求 family、摘要及回执均保留必要的精确读取规则。旧请求按原 family 和原摘要匹配，归一化只读其原发布修订，不读取今天的主线头，也不为重试重新导入。旧写入器只留在历史夹具测试中。

集中验证使用 `scripts/verify-package-exchange.py` 和 Web `package` 动线，复用现有源工程、独立图/资源判据和同一恢复工作区，不新建媒体、ASR 或渲染任务。真实历史撤销/重做可随该动线补一次。独立渲染、故障矩阵、混合历史、大素材持续性能和完整 A7/D8 尚不能由这些静态实现或包检查代替；实际证据见台账。
