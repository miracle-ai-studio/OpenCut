# Web 迁移与全仓审查

2026-09-29。现有 Web 编辑链路已原位迁移为模块化静态应用，由独立 Rust 服务同源托管。没有新增带版本后缀的页面、模块或平行客户端；既有跨进程契约名称保持兼容。

## 架构与清理

工程状态、项目库、素材、效果、时间线、预览、属性、任务及历史分别拥有模块边界。功能模块不能相互导入实现，纯 model/shared 不反向依赖业务状态，workspace 不导入具体页面；SDK 类型来自公共声明。状态控制器按实例注入，工程修改仍经服务端计划、固定修订和原子提交。

Classic 的可调整面板结构与时间标尺被复用。原来的 2,077 行工作区改成装配入口；没有移植浏览器单例、IndexedDB/OPFS 工程存储或另建浏览器渲染权威。删除未使用的 UI 脚手架、重复客户端及失效测试、旧路由/SSR 配置、Cloudflare 示例 API 和对应部署任务。保留协议说明、历史验收收据、恢复资料及必要回归。

服务托管页面、CLI 和 MCP 共用现有宿主。页面无需外部字体或 CDN。开发依赖及运行依赖使用 npm 锁文件；本地交付包包含 Web 静态资源，所有文件进入 hash 清单。

## 2026-09-30 导入性能复查

迁移后的旧协议要求上传前提供整文件摘要，导致 Web 两遍读取。现改为单次读取与一块有界预读；公共流式 DTO 独立声明，旧 DTO 和 132 个既有工具声明保持原样。服务端封存与任务接受保持原子操作，worker 独立验证完整内容；格式识别和不可变保存没有绕过。审查补齐新摘要冲突的 HTTP 409 投影，并以数据库写协议升级阻止旧宿主误读未定摘要状态。

单次读取、只预读一块、取消停止读取及清理分别有前端行为测试；数据库覆盖摘要固定/封存回滚、幂等冲突、旧协议投影、撤权、清理和迁移重开；真实浏览器与 HTTP 覆盖完整媒体链路和错误摘要拒绝。本机 64 MiB 合成 WAV 三轮中位总耗时约 11.97 → 10.41 秒，首块等待约 1.50 → 0.10 秒；这是小样本观察，不作为所有素材吞吐承诺。服务器入库与文件系统持久化仍是后续优化对象。

当前测试、产物、已备份的本机升级与测量明细见[导入优化收据](evidence/stream-upload-2026-09-30.json)。原版完整功能等价、其他浏览器、大规模工程及正式发行仍按前文的未完成项跟进。

## 2026-09-30 连续撤销与重做导航

复核 Classic CommandManager 的两个栈规则后，移除 Web 的单个 redo ID 与“取最新 transaction”猜测。新增服务只读导航，按固定修订的第一父链重建撤销/重做目标；普通新编辑清空重做，选择性操作按原始事务和撤销事务配对，合并作为一次操作，尚未合并的分支不进入主线栈。创建及格式提升不成为普通撤销目标。执行继续调用既有选择性 plan/apply，不绕过固定修订、冲突、权限、hold、幂等和原子提交。

页面只有在导航与当前项目/修订一致时启用操作；刷新、重新打开与远端编辑后从服务恢复状态。撤销项目重命名同步更新项目库。纯应用层使用按顺序索引的集合，存储层一次读取快照，检查循环并限制 100,000 个修订；未增加数据库表、依赖边或浏览器工程存储。

此节取代上一节“连续多次撤销目标解析未完成”的状态。编辑历史导航已实现；撤销删除后恢复先前活动场景/选中对象仍属未完成视图行为。项目复制/删除、场景书签、其余 Classic 差异和正式发行限制继续有效。最终 release + Web 的 25 项浏览器动线通过，无页面异常或失败请求；其中连续两次撤销、刷新后连续重做、重做后再撤销、新编辑清空重做，均按完整工程文档逐步比对。测试及产物身份以[历史导航收据](evidence/history-navigation-2026-09-30.json)为准。
