# 剪辑交互与预览修复 · 2026-10-22

范围：音量曲线手势、普通人工操作、打点、播放器空状态，以及音频／效果／转场资源面板。此记录不代表整个工程或完整剪映功能已交付。

## 连续播放

声音设备作为主时钟，画面落后时丢弃过期帧，保持原来 125／150 ms 画面新鲜度门槛。设备、传输和原生生产者统一为最多 8 个 4096 帧块，设备默认先准备 6 块（较小宿主按原有上限协商，至少 2 块）；每个设备回执仍参与精确消费计数，界面更新合并为最多 30 Hz。不会把静音填充算作已播放声音。

原生 dB 曲线缓存同一 60 Hz 区间的求值端点；现代三次曲线的等值非零段、零纵向切线直接返回该常数，避免 56 次无意义的时间二分，保留非等值及旧归一化曲线路径。旧候选浮点求和的末位噪声不作为这个新路径的 bit 一致性承诺。同一块内，身份不同但全部执行字段及采样时钟相同的音量包络复用精确结果。5 路合并与逐路隔离比较逐样本 bit 一致；时钟、不同音量与不同起点不错误共享。旧线性音量仍逐样本使用原时钟。Rust 捕获当前块的源窗口随既有私有命令传输，源绑定与编译合并一次往返，仍调用同一类型应用方法并检查完整窗口／声音身份。混合器每块只校验一次共享采样表、借用一次声道视图，保持 Float32 累加顺序；独立 WAV→双声道 Float32 的 384000 帧／3072000 字节全量 SHA-256 一致。

声音 FIFO 低于 2 块或正在重新蓄音时，不再启动新的昂贵画面准备，后续权威消费报告恢复准备。真实耗尽后按相同启动水位蓄音再续播，EOF 和画面额度暂停不触发这个重新蓄音条件；首次准备继续显示“正在准备”，不误报成播放中断。每次只补一张画面，最多提前 800 ms；未放宽原生 1 秒准备许可、125／150 ms 像素门槛。画面超时、队列内存不足与授权失败仍分别处理；授权／代次错误不会被当成普通丢帧继续使用。

默认 CPU 画面预算原为 64 MiB。两路 1920×1080 的 16 bytes/pixel 解码准入本身已约 63.3 MiB，尚未计算合成输出、字体和编码缓存。基础绘图预算调整为 **128 MiB**（含字体的执行另保留既有 96 MiB 字体额度，总额 224 MiB），GPU 512 MiB、进程 RSS 2 GiB、编码 32 MiB、源访问与取消围栏保持执行。前景预览二进制读取由每次 64 KiB 合并到最多 **512 KiB**，每次仍使用同一固定素材、原授权与元数据校验；普通音频与隔离渲染回调继续限制 64 KiB。大块与两个上游工作单元的临时字节按最多 8 倍计入预算（包含两条已验证的有界预读数据块），范围缓存上限为 **2 MiB**；额外两条最多 512 KiB 对齐预读数据块受同一额度约束，覆盖重叠请求、跨块、EOF、LRU 淘汰和关闭。向前请求持续使用同一解码迭代器，避免每落后半秒重读关键帧；向后跳转仍重开，覆盖 PTS／间隙／EOF 语义保持。短音频波形整段一次有界请求，长片段使用分块视区，自动滚动不再每像素重投影。原生与 JS 保守预留一致，没有整段复制或无限缓存。独立准入检查对比原 64 MiB 的拒绝、128 MiB 的双 HD 接受和更大实际解码拒绝。已有任务只接受完整、精确的历史 64／160 MiB 或当前 128／224 MiB 策略组合，保留捕获策略执行，不改写历史输入，也不接受混合限额。

最终 Native 为 `e75cb04db1eaba1025d48e5595ceb7723335897b4739526d5fa12d055e190a1b`。最后完整实播的 252 个 DOM 观测从准备、实际发声覆盖至片尾前 41.899 秒，随后确认 42 秒正常结束；准备约 4.98 秒，播放中的 224 个观测未出现缓冲，声音推进 41.642667 秒／实耗 41.625 秒。该观测不是逐量子零缺音证明，也不是物理扬声器听审。随后移除正常音频选择触发的画布警告，补充暂停状态的 5 秒心跳：不移动游标、不改变代次／临时覆盖，不重建解码准备；恢复、跳转、离开或授权失败停止心跳。对应 98 项与 27 项回归、真实长于原租期的暂停／主题截图另验；播放中声音执行代码未改。此前失败和中间候选均保留，不能作为最终通过记录。

**画面连续播放仍未达到交付标准**：上述播放中的 224 个观测仅 84 个有符合新鲜度门槛的可见画面；多层高清切换和绘制仍有跳帧与等待，不能宣称持续 25 fps 或全程流畅。后续需要在 Rust 编排下提供降低预览分辨率或预先渲染的连续预览路径，再做独立像素和同步验收；本轮没有用放宽陈旧画面门槛掩盖它。

暂停与主题补查还修复了位图所有权问题：显示组件保留可重绘的源位图并绘制到画布，切换主题时重画；显示副本与源位图两份计入备帧额度。对应 31 项回归通过。实际暂停截图相隔 **80.22 秒**，画面、零秒位置与暂停状态保持，未见告警。修改显示方式后，另从 18.741 秒观测至 42 秒片尾，其中 122 个播放观测未见声音缓冲；这次补查覆盖多层高清段，但不替代完整跨平台性能验收，也没有把仍会等待的画面记成流畅通过。

## 截图分析

音频面板将“试听”和“添加到时间线”分开；效果显示轻柔／适中／明显预设与明示的示例；转场显示时长预设及示例，只有选中相邻片段时才可应用。播放器固定深色观影表面及控件对比度；浅色波形使用深色描线，主题切换仅重绘原生条形事实。资源卡片、搜索、按钮、菜单沿用统一组件和主题，中文／英文及明／暗四组合均检查横向溢出。画布空状态以播放器窗口为中心；选中音频或当前时刻无画面的片段不再在画面上报选择错误。音量曲线保留选择、视图与保存后的线条，普通编辑恢复提示仅在真实不确定／冲突／失败时显示。

截图也揭示目前的交付限制：高清播放画面仍会等待，资源库只有实际可执行的模糊、交叉淡化和现有声音，未覆盖剪映资源库的全部类型、搜索和自动节拍能力。完整触控／读屏／跨浏览器交付仍未验证。

## 实际操作与数据保护

复用已有 8 秒合成工程，完成打点、播放头加点、拖动、双击加点、一键分割、转场添加与同 ID 更新，以及模糊预设添加和实际静帧预览。9 个已核对归属的事务逐项通过原生选择性撤销还原；完整工程 JSON 与原始字节摘要均一致。海南用户工程的修订和完整内容未变，用户已有分割、音量点、锁定轨道与 Blur 图层保留。

真实页面分别查看中文／英文、浅色／深色，检查资源布局、控件、错误信息及横向溢出。截图路径、服务部署前后四表完整摘要、试听的内容哈希和检查结果记录于同名 JSON。音效试听不会创建项目素材、修订或任务；工程和媒体没有上传到外部服务。
