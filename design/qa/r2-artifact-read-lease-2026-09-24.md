# R2 已发布产物读取租约与路径围栏（2026-09-24）

状态：**下载读取边界通过，统一保留／回收尚未完成。** 成功任务的 `artifact.path` 已由 SQLite 发布，但此前 HTTP 下载先规范化路径、再打开文件并复制到匿名受控下载文件；规范化会抹去最终文件名是否为符号链接的信息，复制期间也没有与未来清理协议共用的尝试目录租约。

现在原生 `ArtifactSource` 在已发布任务的 `artifacts/{job_id}/attempt-{attempt}` 上取得共享 inode 锁，并从锁住的目录句柄以 `openat`／`O_NOFOLLOW` 打开直接子文件。打开前后核对目录身份，拒绝目录别名、最终符号链接、硬链接和非普通文件；HTTP 在校验大小与 SHA-256、复制到受预算控制的匿名文件期间持有该锁。匿名文件在传输结束或取消前仍由现有下载预留保护。未来清理成功尝试目录时必须在同一 inode 上取得独占锁并重检引用。

原生测试覆盖活跃读取阻止独占清理、路径别名与目录替换。真实 HTTP／CLI [媒体动线收据](evidence/r2-artifact-read-lease-product-2026-09-24.json)覆盖完整编辑／预览／导出和产物下载；截断、等长篡改、同内容符号链接与硬链接均被拒绝，恢复原文件后下载成功。该动线仍使用合成音视频，不代表真实访谈理解或浏览器验收。

同一 macOS x86_64 debug 归档（SHA-256 `84b3713700f747fe5131d27a549f9958fed1f00fdda46a6b2a614279160afaf7`，二进制 SHA-256 `2b4ae3a3ed7c6c357ef4ea0d5988db26093ad3fdf7e72e734d592e113b915cd0`）在仓库外通过[35 项整包验收](evidence/r2-artifact-read-lease-package-acceptance-2026-09-24.json)，包含真实 64 MiB 盘满 repair、Worker、双 SDK、项目导入与上述媒体动线。此收据证明该归档和列出的场景，不是 release／跨平台或完整 R0–R7 放行。

此改动尚未提供产物删除 API、历史工程／插件版本的统一引用计数、可审阅清理计划、活跃引用重检和失败恢复；这些仍是 R2 的后续工作。非 Unix 宿主尚无同等级尝试目录租约，跨平台不放行。
