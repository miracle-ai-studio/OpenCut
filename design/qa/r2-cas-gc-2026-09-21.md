## 设计与实现

见 [回收契约](../architecture/cas-gc-contract.md)。纯 DTO → Application 引用/文件端口 → SQLite 持久计划/步骤 → Native 目录锁及描述符删除；四入口和双 SDK 共享同一工具定义。

先计划，再以准确计划哈希显式执行；支持分页发现未完成计划与逐项检查。执行时重新检查全部修订、全部状态任务及项目素材记录，解析 JSON 转义并保护旧式源文件 inode 别名。预算或引用损坏时拒绝删除。CAS 生产者从捕获至 SQL 引用提交持共享目录锁，回收持排他锁；导入任务已有持久固定哈希引用。旧 Host 必须停机后升级，工作区 CAS 必须私有。
