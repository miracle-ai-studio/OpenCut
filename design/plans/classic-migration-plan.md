# Classic 全量迁移执行计划

更新：2026-10-12。本文是唯一执行计划；实际完成情况只更新[交付台账](../architecture/headless-completion-ledger.md)，验收只更新[当前摘要](../qa/acceptance.json)。计划、实现、验收是不同状态。本文取代日期命名的迁移计划、阶段过程报告与重复进度说明。

## 1. 交付目标与范围

完成约定的本机 Rust Server + Web Classic 迁移：57 个功能组、13 个页面及 X01–X03 辅助项逐项核对。当前为 20 指定动线已验、20 部分迁移、14 未迁移、2 待等价验收、1 原版占位；仍有 36 组需要实施或验收。组的大小不同，不换算完成百分比。

已确定：不迁移 Classic 云账户/登录，使用本机身份；字体、贴纸沿用 Classic 来源及许可允许范围。2026-10-12用户允许音效从开放许可渠道获取或自行生成，音效来源不再限于 Classic Freesound；反馈先用明确标注的 mock 接收端。F35 原版占位不要求补造新功能。原生 Desktop、移动端、正式跨平台签名发行、云端协作和原版之外的专业能力维持独立范围，不因本计划标为完成。

20 组已验为 F01–F07、F09、F11–F15、F22、F36、F45、F48、F49、F56、F57。其中 F06 只证明已记录的恢复动线；新增文字、蒙版等模型后仍需补历史工程转换与组合回归。F57 按已确定范围使用本机 mock，真实邮箱保持范围外。F10 已接入完整 V4 工作区、时间线标记、画布备注、精确时间与选择性历史；授权源预览与normal静帧PNG已验，备注排除PNG已验；连续播放与视频导出的备注排除仍待验，保持部分迁移。

## 2. 分工与模块边界

按用户要求，多位 Agent 工程师并行开发，主 Agent 负责整体审查、协调交接、集成验证及跨模块难题。同一公共模型、数据库迁移和发布候选只有一个集成入口。

各批先冻结文件职责和共享契约，再并行实施。当前S1剩余工作按3.4分工，后续文字字体批按3.3分工。主Agent负责共享入口、公开注册、数据库迁移、产品接线及集中验收。交接须说明已实现语义、未覆盖边界和受影响检查；共享入口、迁移编号、生成协议和候选构建由主Agent统一处理，不并行启动Cargo或有状态媒体验收。

|职责|主责位置|交付物与交接|边界|
|---|---|---|---|
|模型与精确语义|`contracts`、`time`、`editor-core`|版本化文档、操作、不变量、参数和时间空间；交给应用与编译层|纯函数；不访问文件、数据库或网络|
|应用与事务|`editor-application`|固定修订计划、权限、幂等、冲突、撤销及端口；交给原生适配|不调用内部 CLI，不构造原生实现|
|存储与宿主|`sqlite-store`、`asset-store`、`native-services`、`host-runtime`|唯一工程权威、原子提交、迁移、资源身份和宿主装配|书签/字体/音频状态不得成为另一份可变工程|
|合成与媒体|`composition`、`project-render`、`media`、`job-runtime`|源文档→IR→后端、实际像素/PCM、任务恢复/取消|编译层保持纯；发布继续受租约和围栏控制|
|公开协议与 SDK|`api-contracts`、`automation`、CLI/HTTP/MCP、`sdk-rust`、`sdk-ts`|同一声明生成工具/OpenAPI/类型，统一应用语义|已发布 schema 冻结，内部准备对象不进入公共 DTO|
|Web 产品|`apps/web/src/editor` 各现有功能模块|呈现、交互草稿、命令提交、任务观察和焦点路由|不复制领域规则、不写第二套内容状态|
|验收与集成|`scripts`、各模块测试、Web 验收用例|需求→检查映射、独立参考、候选身份与一次性阶段结论|不按测试数量代替功能等价；不累积过程报告|

沿用现有模块化单体与 Worker。新增依赖必须有边界理由；不为通过检查扩大依赖 allowlist，不为迁移新增空壳 crate 或微服务。

工程扩展采用新的版本化完整聚合，沿用现有项目 ID、修订、事务、审计和素材权威。V4基础存储屏障为 DB27，恢复V1为DB28，本批通用恢复V2为DB29并保留V1原始记录，工程为 V4，独立帧图为 IR4；公开操作与工程包版本在对应纵切面发布时登记；书签不得采用独立可变旁表绕过工程历史。未来能力只有完成整个执行链后才对客户端公布为可用。

必须提前固定的已知差异：

- Classic FPS、画布尺寸/模式/原始尺寸和背景均为工程全局设置；场景没有覆盖项。任意场景的 raw FPS 比较、空场景首视频覆盖及首视觉尺寸变化必须更新同一工程事务。当前 V3 只提高当前场景的 F08 实现仍属部分；新模型不沿用这种不同终态。
- 源音频“分离”关闭原视频音频并创建同源音频元素；Classic 的“恢复”重新开启原视频音频，保留已分离元素。恢复不等于删除分离元素或撤销，两者测试预期分开。
- 音量线沿用 Classic 的 -60…20 dB、0.1 dB 步进及非线性显示映射；已有动画音量的显示规则按源码处理。旧线性 0…4 合同不能冒充完整 20 dB 范围。
- 过冲曲线沿用 Y=-0.5…1.5、Pop 和自定义预设；受限参数如何处理过冲必须显式规定，旧 0…1 合同保持原义。
- 时间使用精确有理数，分别定义源时间、场景时间与片段局部时间；FPS 提高、变速、拆分、字幕和曲线不得各自量化。
- 自由文字与字幕有独立身份；浏览器与 Worker 使用可核对的相同字体字节。预览辅助书签/选择框不进入导出。

### 3.1 正在实现的共同契约

采用新工程 V4 完整聚合，不再扩大 V3 的 `base/visual/keyframe_curves` 旁挂模型。新项目和 Classic 完整导入使用 `ClassicGlobal` 设置；旧 Rust 工程若各场景尺寸/FPS 不同，使用明确的 `LegacyPerScene` 保留 profile，进入全局编辑需显式转换并列出差异。不得默取当前场景设置而称无损。内容、书签、字体、效果、蒙版和通道始终属于同一工程修订。

工程 V4、IR4 和 DB27 已实现；初期V4基础候选的24项版本化工具注册与SDK证据属于历史范围，包6仍是后续设计。DB27只在临时库验收，未升级用户库。旧 DTO、工具和历史字节冻结；新增操作从共享声明生成。旧修订只读可查，提升和撤销以完整聚合追加修订，不能普通撤销就无提示降级 head。旧包/库的读取、提升、复制/分支/merge、选择性历史和包外恢复需一并贯通后放行。

纯类型模型、领域结构验证、旧 Rust V1/V2/V3 转换、参数目录和动画采样已实现并集成。V4 创建、提升、固定修订读取、编辑、恢复、复制和分页已通过应用端口接入 SQLite；书签嵌入完整修订。DB27 为协议屏障，不改写历史文档。独立帧 IR4 已接入动画字段、音轨参与判断和精确源时钟；公开 V4 操作、选择性历史与部分 Legacy 原生帧适配已经接入，Web 已接入备注/历史和只读内容检查；浏览器音频进程和完整场景 WAV 持久任务/下载已接入并验收；固定样本范围WAV已贯通；连续seek、完整视觉后端和视频导出仍未贯通。检查范围以交付台账为准，渲染支持独立于可保存的类型声明。

旧 Rust 转换是纯函数，资产版本由调用方显式提供，不探测或读取资源。保留原ID、精确时间、线性增益、旧场景格式、字幕覆盖轨、效果/蒙版顺序和曲线独立ID；未知metadata、CAS冲突、不可表示内容集中报告，拒绝结果没有可提交的部分工程。音轨存在但格式未知以 `Present { metadata: None }` 保留，不编造采样率或退化成Unknown。旧媒体缺少source_range、约分速率超u32、跨通道重复ID/绑定、无内联内容的Text/Subtitle片段等仍会明确拒绝，不能称为任意旧工程无损迁移。Classic浏览器工程转换、资源补齐和真实历史/包恢复仍待接入。

参数目录覆盖当前40个标量、5个颜色、2个离散声明，区分存储合法值、UI提示及求值后物理规则；静态默认值仍由内容模型和后续创建用例定义。Classic dB先裁至-60…20再转线性幅度；opacity是图层乘数，文字padding保留有限过冲值，不能套UI范围统一裁切。形状边数与蒙版尺寸等按各自源码规则投影；字体大小/行高非正的实际采样明确失败。编译/后端能力拒绝与六项 Legacy 原生独立像素样本已通过；完整 Classic 图形/字体执行仍未完成；未母带 V4 PCM 子集已有独立采样验收，保持音高与整场母带已有共享浏览器适配及独立 WAV 子集证据，生产固定修订桥、准备后PCM绑定和持久Worker WAV任务/围栏发布已通过真实Chromium验收；完整视频音频矩阵仍待补齐。

采样返回原始值及物理值，元素局部钟不受源裁剪/变速改变，轨道使用场景钟。精确时间先相减再计算相对浮点比例，避免大tick相邻关键帧合并。支持step、linear、真实时间/值Bezier及hold/线性外推；旧归一化曲线单独保留Native的32段查表、40次求解和12位常量profile，不冒称与旧拆分算法或所有渲染器逐位一致。真实Bezier缺失柄按段长和值差各自默认；相同端点的鼓包/负过冲不被扁平化。

字幕有明确所属字幕轨；旧全局字幕提升需显式默认覆盖轨。音轨探测以 Unknown/Absent/Present 三态保存，未知历史不误判无音轨，显式分离/恢复仍需实际能力检查。Locked 文字/文字蒙版的具体字体face须匹配400/700及样式，切样式时同时原子更新字体绑定；不默认合成。Classic浏览器斜体合成及变量字体实例仍需执行契约与独立图像证据。

Classic真实timebase为120000；源120001 ticks、rate2的合法逆舍入终态是timeline60001 ticks，请求span为120002 ticks。请求时钟不能直接作为解码/CAS读取窗口，也不能强拒合法编辑终态。后续IR/native必须分离资源内读取范围和EOF行为；视频空帧与音频零尾需独立样本验证，不擅自设为末帧保持。Bezier缺失柄的默认控制为±段长/3、±值差/3，编辑模式提示不覆盖已存控制。

|共同语义|固定原则|
|---|---|
|时钟与裁剪|精确有理时间；区别工程时间、元素局部动画时间和源取样时间；非媒体的历史裁剪也必须可恢复；每种时间只保留一份权威|
|音频与增益|源音频开关独立；Classic dB 与旧线性增益显式区分，零增益和旧线性通道不得转换失真|
|字体与排版|内容锁定字体资源；独立文字与字幕各有布局 profile，字体绑定只有一份；Classic 字号按布局高度/90换算，背景padding按字号/15换算，offset不随字号缩放|
|图形与合成|17种 blend 全枚举；有序效果与效果层；Classic clip blur、工程主轨背景blur和旧Gaussian radius为不同参数 profile|
|蒙版与动画|元素局部蒙版与旧画布坐标显式区分；稳定控制点/效果/蒙版引用；原始时间/值切线和外推，不丢相同端点但有鼓包的曲线；UI范围不冒充导入存储上限|
|兼容边界|未解析字体、不支持通道/节点和转换损失必须报告，不能靠投影成字幕或静默删除通过验收|

P0.2/P0.3 已有上述纯模型、验证、参数规则和旧 Rust 转换样例；Classic 创建默认值及完整内核夹具已补齐；选择性撤销/重做与导航已接入；仍需 Classic 转换、完整示例产品动线及工程包贯通。旧Graphic层叠保留元素数组顺序，只有全为Legacy profile的Graphic轨允许重叠；旧形状opacity不乘轨道opacity，旧图像/视频则相乘，IR4 已按 profile 保留此差异，Legacy 帧后端已有独立像素证据，Classic 后端仍需实施。字体尺寸动画在 Classic 的 UI 声明与实际布局读取间不一致，目标需实际执行；多蒙版和动画蒙版按目标架构验收，不能冒称原版已具备。P0.4 仍须用独立像素/PCM确定执行语义和预算，纯采样测试不解除此门槛。

### 3.2 已实现底座的使用边界

具体通过范围与候选身份只保存在[交付台账](../architecture/headless-completion-ledger.md)和[验收摘要](../qa/acceptance.json)，本计划不复制逐轮测试数量、构建hash与故障流水。

- V4完整快照、授权资源流、媒体规划、历史、WAV持久任务、normal静帧PNG、实时声音和媒体手势/剪贴板均已有指定范围实现；完整Classic转换、包6、全元素交互、连续画面和视频导出仍按阶段出口完成。
- 公共DTO隐藏locator/原生路径/权限；固定修订绑定完整资源版本，hash不替代授权。准备、执行、流读取和SQL发布复核原caller与本机策略，沿用CAS保护、租约、幂等、取消优先和发布围栏。
- Web沿用唯一controller与互斥旧/V4会话；提交原公开事务，不投影为旧工程，不重建媒体/任务/历史权威。源音频恢复与撤销保持不同语义。
- 音频逐sample计算轨道/元素gain；源时间、片段局部时间、场景时间分离。Native Legacy与Classic的量化、重采样、priming/EOF、声道映射、SoundTouch和WebAudio母带显式分profile。范围/seek保留所需DSP历史，不以FFmpeg近似流程宣称等价。
- 帧适配只消费已采样IR4，以宿主授权resolver绑定资源；文字、复杂形状/混合/蒙版与背景等未支持节点明确拒绝。Worker沿用原提交者权限、真实子进程退出和有围栏的产物发布；不开放旧V3视频导出承接V4。

## 6. 验收依据与组合矩阵

- 几何/图形：独立几何坐标、边界和 alpha；混合模式用独立公式，不能把同一渲染器输出当期望值。
- 文字：固定合法字体、字节身份、中文/拉丁度量、换行/装饰/背景样例；字体缺失和缺字状态明确。
- 音频：已知频率、增益和脉冲；检查源裁剪/分离、变速、音高、静音、曲线和轨道混合后的 PCM。
- 事务：固定修订、一次手势一次提交、幂等重放、同键异参拒绝、锁轨/权限、部分失败回滚、撤销/重做及独立后续编辑。
- 恢复：旧库/原媒体保持安全，丢失回执重试、旧版转换、新元素组合、工程复制和包外重开；不可恢复的数据明确报告。
- 交互：文本/IME/弹窗/时间线焦点、拖动取消、连接/工程切换、过期回包、刷新与真实系统剪贴板；自动化不能覆盖的系统行为单列实际环境验收。

先建立“元素类型×操作”和“参数×动画/渲染”适用表。每个适用格必须有证据；不适用格记录原因。用共享夹具覆盖多个要求，计数按需求去重。性能门槛在优化前固定，记录指定机器/样本的冷热成本、内存及缓存淘汰；不宣称跨机器通用指标。
