## 1. 目标、复用与重构边界

交付范围仍是本机Rust Server + Web的Classic迁移。Classic云账户/登录排除，采用本机身份；字体/贴纸遵守已确定来源与许可，音效可用开放许可或自行生成，反馈保持已验mock。F35为原版占位。Desktop、移动端、跨平台签名发行、云协作及专业选片/稳像/跟踪等另属长期产品目标。

|部分|实施决定|允许重构的触发与出口|
|---|---|---|
|V4工程、精确时间、原子事务、历史、CAS、Job/lease|直接复用；不再做一轮模型/存储/播放器重建|仅在可复现缺陷或具体新增语义无法表达时改；保持固定修订、幂等、权限、取消和发布围栏|
|Classic算法和资源|先定位并复用已实现的源节点、几何路径、shader、布局及编码选项；已迁入适配层的算法直接接消费者，只有依赖无法隔离时才做等价移植|浏览器实现留在原生/Web适配层；Rust持有采样、授权和资源契约。浏览器单例、IndexedDB/OPFS、当前选择状态不得进入Rust内核；原版输出之外还需独立数值/像素/PCM预期|
|合成执行|Rust快照→采样IR→授权绑定→现有栅格/GPU/音频适配；PNG/播放/导出共用节点语义|图形接入时识别重复的帧分派、资源收集和生命周期胶水，在原模块内按typed能力收敛；旧profile行为保留，不复制一套图形播放器/导出器|
|公共协议|共享Rust声明生成SDK/OpenAPI/工具；旧DTO冻结|先写出不兼容点，再决定新版本；不为内部helper改名新增工具，也不为了少改文件放宽旧schema。内部类型不得携带公开原生路径|
|Web|继续唯一V4Session/controller、交互草稿与正式应用事务|同一元素能力描述供菜单/Inspector/快捷键/操作禁用消费；Rust仍校验。先复用已有接口，出现真实重复再提炼，不预建通用UI框架|
|架构治理|模块化单体、宿主注入、原生适配；默认不加crate/服务/运行时|新增边界/依赖必须说明具体责任及生命周期，手工审查dependency-policy；不得通过重生成allowlist放行|

重构必须附带可检查的收益：删除哪条重复执行分支、让哪个缺失消费者接入，或修复哪个行为。仅目录更整齐、文件更少不构成当前迁移前置。迁移后删除旧实现须证明没有消费者且必要回归仍覆盖；Classic对照源码与冻结协议保留。

## 4. 并发所有权与统一验证

- 先并发实现，后集中集成验证；实现阶段可编写测试/独立参考，但不逐任务启动Cargo、生成、Web构建、浏览器或媒体任务。静态源码核对和接口审查用于实现，不冒充验证结果。
- 一个集成者拥有共享契约出口、工具/领域动作/分派/权限、SDK生成、全局Web接线、Cargo构建和有状态验收。Agent只改明确拥有的新模块与现有文件，不自行修改全局入口或依赖baseline。
- Agent尽早交冻结DTO、Classic来源、调用接口及接线清单；随后完成自己的实现。交接写清已实现、未接线、待验证和真实缺口，不能以编译通过或Agent完成代替迁移完成。
- 各独立任务可连续推进，不以一次验收阻塞下一任务。共享接口变更按依赖顺序合入，仍只在统一集成后产出候选。确有正确性缺陷则修复并重建受影响候选，不承诺一次构建永不修正。
- 统一阶段先审完整注册链，再运行下节要求的架构/生成/wire/行为检查，用同一显式二进制和Web候选串行验收原合成工作区。成功请求、Job、素材和独立参考按身份复用；不删现场，不为观察器修正重编产品。
- 状态分为“待实现/实现中/已实现待集成/已集成待验证/已验”；原F验收状态只有通过其完整合同后才更新。不能把用户要求延后验证解释为跳过验证或提前宣布全量完成。

当前补充D7实现审查发现四个真实缺口：预览unknown请求仅内存恢复、包6不含历史闭包、公共站点RSS/sitemap及首HTML元数据、本机浏览器会话缺少过期/退出。分别沿原预览恢复、CAS/历史事务、Classic站点源和HttpOnly同源会话边界补齐，不能只列为验收未覆盖。

边界审查：CLI静态站点HTTP适配层新增对仓库已锁定`ureq =3.2.0`的直接依赖，仅用于固定公共内容上游的有界GET和首HTML/RSS/sitemap组装。无工程文档、媒体、CAS或编辑求值进入该适配；不调用内部CLI，不新增crate、运行时或迁移例外。`dependency-policy.json`仅手工增加该一条已审依赖，其余baseline保持；退出条件为固定源/响应预算/转义/错误码和会话生命周期的行为门禁，未来独立HTTP宿主抽取时随适配整体移动。

## 6. 不重新讨论的语义与验收下限
