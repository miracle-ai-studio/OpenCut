# 当前交付状态

当前代码提供本地 CLI/HTTP/MCP 服务、SDK 和 Web 剪辑工作台。完整功能及跨平台发行验收尚未完成。机器可读范围见[状态摘要](status.json)。

现有能力包括工程与因果历史、素材上传导入、多轨剪辑、文字字幕、图形效果、混合蒙版、转场、固定修订预览与输出、授权资源、任务取消恢复和工程包。来源解码器、数据库升级、许可证和固定依赖元数据属于必要支持代码。

项目首页使用实际工程封面与元数据，提供继续剪辑、搜索、排序、视图切换和工程包导入。旧浏览器 Classic 恢复功能已退出，已有工程、历史和共享渲染能力继续保留。

## 当前验证范围

- Rust 公共声明包含 184 个操作、12 个领域；同一显式程序通过生成与规范检查，CLI 与生产网页构建通过。
- 来源图形相关 Web 测试 29 项、前端边界测试 23 项、后端测试 14 项通过。真实 Chromium 解码与 100 次缓存读取测试通过；架构和契约边界检查通过。
- 显示缓存为 64 MiB，宿主缓存保持 32 MiB，同一服务工作区单解码。后台解码忙碌时按请求顺序排队，活动与等待请求共受 256 个上限约束，保留取消、权限和期限校验。
- 三个同时发起的真实 HTTP 波形请求全部成功；两个编辑器页面完成资源加载，显示明确的排队/生成提示。当前一个工程的 59 个修订、58 笔事务与更新前内容一致。

当前候选的一次前台可见 42 秒播放呈现 1047 帧、丢弃 3 帧，最长墙钟画面更新间隔约 1.28 秒。24 秒处一帧准备约 1.42 秒，其中解码约 1.11 秒。预览仍有明显停顿，流畅性验收保持未通过；本次缓存和排队修改不构成预览性能修复。

完整回归须针对实际发布候选执行。

## 已知限制

- 完整导出像素/性能、任意编辑和 seek、故障恢复、大工程、长片、多设备、多浏览器与物理输出矩阵尚未全部验证。
- 长源完整播放存在进程树驻留内存超额问题；macOS 使用监测后终止，不能宣称内核硬配额。
- 一次母带后 PCM 高 DC 残差的原因未确定；后续健康窗口不代替原因证明。实时与导出不同采样策略的完全等价尚未全部验证。
- 字体与颜色派生具有限定来源和运行证明，逐字体、平台、预算及持续帧率覆盖不完整。品牌目录仅开放许可准入条目。
- 音效提供方的真实故障、取消和期限组合有缺口，未配置的可选提供方不能当作可用。
- 工程包依赖、分支合并、故障矩阵、完整签名、安装、升级和跨平台分发未全部验收；GPUI Desktop 是独立壳。
- 部分保留的组合/兼容性验收脚本仍有旧接口假设，尚未完成维护，不能算作当前候选已通过。
