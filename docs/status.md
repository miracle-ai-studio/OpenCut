# 当前交付状态

当前代码提供本地 CLI/HTTP/MCP 服务、SDK 和 Web 剪辑工作台。完整功能及跨平台发行验收尚未完成。机器可读范围见[状态摘要](status.json)。

现有能力包括工程与因果历史、素材上传导入、多轨剪辑、文字字幕、图形效果、混合蒙版、转场、固定修订预览与输出、授权资源、任务取消恢复和工程包。来源解码器、数据库升级、许可证和固定依赖元数据属于必要支持代码。

项目首页使用实际工程封面与元数据，提供继续剪辑、搜索、排序、视图切换和工程包导入。旧浏览器 Classic 恢复功能已退出，已有工程、历史和共享渲染能力继续保留。

## 当前验证范围

- 同一显式 Rust 程序通过生成与规范检查：184 个操作、12 个领域。CLI 与生产网页构建通过；架构 14 项测试、22 个模块零例外及契约边界检查通过。
- 本次界面相关 Web 测试 91 项、素材权限相关原生测试 7 项通过，前端边界检查覆盖 260 个文件。编译争用时超时的三个前端测试已串行复测通过。前一预览候选的 95 项 Web、204 项渲染器及 48 项前端门禁结果仍只对应其记录范围。
- 切点预热使用已有授权范围读取和解码器；两秒预渲染片段使用已有输出任务与发布校验。原生逐帧 IR 决定片段内容标识，编辑后仅重算变化窗口，复用时保留原任务回执与固定修订。
- 首次播放先校验分段清单并显示准备状态，重播通过新会话的原生画面身份重新授权已有缓存。尚未就绪的片段使用实时画面。缩略图/波形显示缓存保持 64 MiB，其宿主解码并发保持 1。

上一预览候选（原生程序 SHA-256 `740f4c42…`、原工程修订）完成海南 42 秒工程的首播、重播、标题位移后重播、跳至 24 秒和反向跳至 12 秒，均无丢帧、无音频欠载；三次完整播放各呈现 1050 帧，两次跳转分别呈现 450、750 帧。最长墙钟画面提交间隔分别为 54.8、53.3、58.6、48.0、48.4 毫秒，均通过未放宽的 125 毫秒门槛。原候选最长约 1.28 秒。

测试将开场标题右移 24 像素，只新增 0–6 秒内三个两秒片段任务，其余 18 段复用；随后通过工作台因果撤销恢复原工程内容。该轮测试保留原 59 个修订、58 笔事务。此次界面验证前已有的 62 个修订、61 笔事务也逐行保留；验证添加与因果撤销后现为 64 个修订、63 笔事务，用户新增的模糊图层保留。

未缓存的实时路径仍观察到 24 秒处约 568.7 毫秒停顿，不属于流畅性通过范围。高质量 AVC 缓存是有损预览：单帧独立来源对比 PSNR 为 34.13 dB，通过 30 dB 探针门槛；SSIM 为 0.947518，未通过 0.98，严格像素验收仍开放。以上性能证据不构成完整产品、任意工程或物理声画验收。

界面现提供固定可见的新轨道投放区、单行图标工具栏、悬停两秒文字提示和保留编辑状态的属性面板折叠。素材缩略图的加号与圆形预览按钮已移除，双击和更多菜单仍可预览。中文界面的默认场景、片段后缀、效果层、素材说明与权限错误均本地化，保存的素材名称保持原样。

真实页面已通过素材放置设置，将原工程视频添加到新轨道并撤销验证添加，工程内容恢复为用户已有状态。拖拽命中与横向滚动坐标通过事件测试，原生拖拽手工矩阵仍待补充。当前服务修复了旧临时导入登记缺失被误判为无权限的问题：已授权工程的固定素材可继续放置；存在的登记仍严格校验工程范围和版本。上述旧预览性能结果不代表此次程序和用户新增效果层已重新完成播放性能验收。

## 已知限制

- 完整导出像素/性能、任意编辑和 seek、故障恢复、大工程、长片、多设备、多浏览器与物理输出矩阵尚未全部验证。
- 长源完整播放存在进程树驻留内存超额问题；macOS 使用监测后终止，不能宣称内核硬配额。
- 一次母带后 PCM 高 DC 残差的原因未确定；后续健康窗口不代替原因证明。实时与导出不同采样策略的完全等价尚未全部验证。
- 字体与颜色派生具有限定来源和运行证明，逐字体、平台、预算及持续帧率覆盖不完整。品牌目录仅开放许可准入条目。
- 音效提供方的真实故障、取消和期限组合有缺口，未配置的可选提供方不能当作可用。
- 工程包依赖、分支合并、故障矩阵、完整签名、安装、升级和跨平台分发未全部验收；GPUI Desktop 是独立壳。
- 部分保留的组合/兼容性验收脚本仍有旧接口假设，尚未完成维护，不能算作当前候选已通过。
