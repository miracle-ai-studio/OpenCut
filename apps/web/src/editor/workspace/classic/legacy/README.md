# Historical source codecs

These pure transformers are copied from Classic's MIT-licensed migration input
code. `provenance.json` identifies each original and adapted copy by SHA256.
The enclosing adapter never invokes Classic's database mutation runner.

Frozen historical defaults belong to their specific input format. Modern editing,
analysis, media resolution and atomic recovery stay in the native application.
See [the adapter boundary](../README.md) for adaptations and current limitations.
